### Part 2 — `functions/model-picker.js` (rewritten)

- **(a)** `preview` / `exp` / `experimental` are now **excluded**, not penalised. `score()`
  returns `-Infinity`, so one `Number.isFinite` check is the only gate that matters.
- **(b)** `NON_TEXT_MARKERS` gains `image`, `transcribe`, `robotics`, `computer-use`,
  `deep-research`, `antigravity`, `omni`, keeping all eight the old regex already had.
- **(c)** `pickModel(ai, logger, role)` with `role` ∈ `gate | extract | vision`, a per-role
  env pin (`GEMINI_MODEL_GATE` / `_EXTRACT` / `_VISION`) and a per-role cache entry.
  `GEMINI_MODEL` still works as a legacy all-roles pin.
- **Floor:** `MIN_GENERATION = 3`, named and exported, overridable with
  `GEMINI_MIN_GENERATION`. Nothing below it is selectable by discovery; if nothing clears
  it, `pickModel` throws rather than guessing.
- `rejectionReason(name, role)` returns *why* a model is ineligible, and the rejections are
  logged alongside the selection.
- The selection log line now carries `role`, `policyModel`, `matchesPolicy` and `rejected`.
  A divergence from policy emits a `warn`.

Supporting: `functions/index.js` passes `"extract"` explicitly; `functions/package.json`
gains `"test": "node --test"`; `firebase.json` adds `*.test.js` to the functions deploy
ignore list so tests do not ship.
